# GOODCY CONTENT

Standalone social platform front-end for GOODCY Company.

## Included
- Responsive social feed, explore, create, inbox, profile and settings views
- Local demo posts with image/video previews, likes, comments and share action
- Editable profile and local browser persistence
- PWA manifest, app icon and service worker

## Deployment
This is a standalone app directory in the GOODCY GitHub Pages repository. With GitHub Pages enabled for the repository, open:
https://goodcyadesuyi-droid.github.io/Goodcy-website/goodcy-content/

## Production requirements
This is a front-end prototype. Public multi-user publishing, real accounts, secure authentication, cloud media storage, direct messages, notifications, moderation/reporting, rate limiting and database persistence need a trusted backend and provider configuration. Browser-local demo data is not public and is not a secure account system.
