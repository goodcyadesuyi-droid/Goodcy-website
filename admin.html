Dashboard information planned

  • Total verified payments received
  • Number of customers who paid
  • Individual transaction references and dates

  • USD settlement status to the approved Zenith Bank USD domiciliary account

Only an authenticated owner role should see the full dashboard. Each customer should see only their own payment status and receipt.

Required before activation

  1. Configure a secure server-side backend and database.
  2. Connect Paystack with secret credentials stored only on the server.
  3. Verify payment webhooks and reconcile actual USD settlement records.
  4. Enable owner-only authentication and role-based access control.
  5. Test that ordinary members cannot access admin records or API endpoints.
